# 드론 공역 지도 (대한민국)

지도에서 비행금지구역·관제권·비행제한구역을 보고, **주소를 입력하면 그 지점에서 드론을 날릴 수 있는지** 판정하는 앱입니다.
하나의 코드로 **웹 브라우저**, **설치형 앱(PWA)**, **Android/iOS 네이티브 앱(Capacitor)** 에서 모두 동작합니다.

## 기능
- 지도에 공역 표시 (금지 = 빨강 면, 관제권 = 보라 점선, 제한 = 주황 빗금, 원전 외곽 = 빨강 점선)
- 범례에서 유형별 켜기/끄기, 확대 시 공역 이름표 표시, 판정 지점에 걸린 공역 강조
- 주소/장소 검색 → 해당 지점 판정: **비행 가능 / 비행승인 필요 / 비행 불가**
- 지도 아무 곳이나 탭해서 판정, ◎ 버튼으로 현재 위치 판정
- 근처 공역 경고 (경계 2km 이내)
- URL로 바로 조회: `index.html?q=서울 여의도공원` 또는 `?lat=37.52&lng=126.92`
- 오프라인에서도 내장 데이터로 판정 (서비스 워커 캐시)

## 드론 정비 3D 시뮬레이터

**진행 방식**: 시작 화면에서 이름 입력 → START(타이머 00:00부터 증가) → 하드웨어 설정 → 소프트웨어 설정(왼쪽 3D, 오른쪽 미션플래너식 순서 메뉴) → 테스트 → 완료. 교육생은 '종료'를 누르면 끝나고, 기록(날짜·이름·소요 시간·무엇이 잘못됐는지와 발생하는 문제)은 관리자 저장소(게시 페이지의 공유 기록)로 자동 전송됨. 전송 실패 시 기기에 보관했다가 다음 접속 때 재전송. 관리자(페이지 소유자·편집자)에게만 상단 '기록 관리'가 보이고, 날짜별 기록 확인과 엑셀 저장 가능. 모든 부품(하판·상판·붐대·스키드 포함)이 분리된 채 작업대에 정렬된 상태로 시작.
`simulator/index.html` — 쿼드콥터를 작업대 위에서 직접 조립·배선하고, 미션플래너 설정 메뉴를 따라 설정한 뒤 결과를 눈으로 확인하는 학습용 시뮬레이터입니다. (`npm start` 후 http://localhost:8080/simulator/)
- **시동까지의 절차 (실제 순서)**: ① 조종기 전원 → SYS Calibration(스틱 끝까지) → 스틱 모드 Mode 2 ② MDL: 내장 RF MULTI, 프로토콜 FrSky D(R8), 믹서 AETR + CH5 스위치, OUTPUTS에서 CH2 반전(또는 RC2_REVERSED), 페일세이프 No pulses ③ 바인딩: 조종기 Bind(신호음) + 수신기 바인드 버튼(전원 넣은 뒤 누르기, 또는 누른 채 전원 넣기) → LED 초록 ④ FC: 프레임 클래스·타입 → 가속도계 → 나침반 → 라디오 교정 → ESC 교정 → 비행 모드 → 페일세이프 ⑤ FC 재부팅(나침반 교정·프레임 변경 후 필수, 배터리 분리도 재부팅) ⑥ 안전 스위치 → 스로틀 최저 + 요 오른쪽으로 시동
- **시험용 화면**: 하드웨어 단계에는 부품 목록·배선표·정답 화면이 없고, 자동 조립·자동 설정·고장 훈련도 학생 화면에서 제외. 결과(무엇이 안 되었는지, 어떤 문제가 생기는지)는 완료 후 엑셀 '상세' 시트에만 기록
- **조종기(TX12 형태)**: 작업대의 조종기를 누르면 조종기 화면이 열림. 모델 이름, 내장 RF·프로토콜(R8 수신기는 FrSky D), 바인드(신호음), 페일세이프, 믹서 CH1~8, 스틱 모드 설정. 수신기 LED: 전원 빨강, 연결 초록, 조종기 꺼짐 빨강
- **케이스(덮개)**: 상판을 단 뒤 씌우는 유선형 덮개. 씌우면 상판 위 부품을 장착·분리하거나 FC 포트에 꽂을 수 없음(벗기고 작업). 안 씌우면 결과에 주의 항목으로 기록
- **전원 커넥터**: 하판 주전원 +/− 선은 납땜된 XT60F, 배터리는 XT60M → PMU 입력 XT60F, PMU 출력 XT60M → 하판 주전원 XT60F. 전원이 들어오면 ESC 시작음
- **수신기**: FC에서 RC 선으로 전원이 들어오면 LED가 빛남(전원 빨강, 연결 초록), 위에 빨간 BIND 버튼
- **FC 확대 배선**: GPS·수신기·PMU 선을 든 채 FC를 누르면 FC가 확대되고, 포트를 누르면 꽂힌 뒤 원래 시점으로 돌아감
- **효과음**: 부품 장착(툭), 커넥터 체결(딸깍), XT60(철컥), 바인딩 완료(두 음)
- **화질**: 반사 환경광·톤 매핑, 카본 직조 질감, 둥근 모서리 부품, 나무 작업대. 느린 컴퓨터에서는 자동으로 화질을 낮춤
- **모터 방향**: 모터에 방향 표시 없음. 돌 때만 위에 회전 화살표가 보임. 반대로 돌면 모터선 두 가닥을 바꾸거나 SERVO_BLH_RVMASK로 반전
- **화면 구성**: 3D 작업대가 화면 전체를 쓰고, 하드웨어·소프트웨어 설정·테스트 메뉴는 위 버튼으로 불러오는 떠 있는 창(끌어서 옮기기 가능). 부품은 3D에서 끌어 원하는 장착 자리에 붙이고(상판 여러 자리·마스트·하판·암 등, 틀린 자리도 가능), 선 끝을 누른 뒤 단자·패드·FC를 눌러 연결. '상판 투시'로 상판 아래 PDB 패드와 ESC 선을 볼 수 있음
- **하드웨어 조립**: 20L급 농업용 4축 형태(원통 카본 붐대·접이 관절·분사 노즐·사각 몸체·높은 착륙장치, 축간 약 1.6m). 모터(축 나사 방향 2종)·ESC·프로펠러(뒤집어 끼우기 가능)·FC·파워 모듈·배터리·GPS·수신기·텔레메트리를 360° 돌려 보며 장착. 하판 PDB 패드의 전원선 극성, 모터선 3가닥 순서, 커넥터 모양(6핀·4핀·3핀)별 FC 포트 배선. 화면에는 규격·정답을 표시하지 않고, 정답은 '정답 확인'에서만 볼 수 있음
- **모터·ESC 선**: 모터에서 3상 선 3가닥, ESC에서 3상 출력 단자(A·B·C)·전원선(빨강·검정)·신호선(3핀 서보)·통신선(단선)이 나옴. 모터선을 단자별로 따로 연결하며, 한 가닥이 빠지면 떨기만 하고 두 가닥이 한 단자면 단락으로 멈춤. ESC 통신선은 하네스로 모아 FC 시리얼 포트(SERIALx_PROTOCOL=16)에 연결하면 모터 테스트·비행 화면에 ESC 텔레메트리(RPM·전류·온도·전압)가 표시됨
- **FC 세부 보기**: 장착한 FC를 선택해 '세부 보기'를 누르면 Pixhawk 포트 배치도(DF13 2·3·4·6·7핀, USB, 뒤쪽 서보 레일)가 열리고, 케이블을 골라 포트에 직접 꽂음. 커넥터 모양이 다르면 들어가지 않고, 같으면 틀린 포트에도 꽂힘. 부저·안전 스위치 포함
- **소프트웨어 설정**: 프레임 타입, 가속도계·나침반·라디오·ESC 교정, 비행 모드, 페일세이프, 배터리 모니터, 서보 출력, 보드 방향, 튜닝, 전체 파라미터 (ArduCopter 파라미터 이름 사용)
- **테스트**: 시동 전 점검(PreArm), 모터 테스트(A~D), 자세 센서(HUD), 비행 테스트(Stabilize/AltHold/Loiter/RTL/Land, 라디오·배터리 페일세이프), 고장 진단 훈련
- 틀리게 조립하거나 설정하면 그 결과(전복, 제자리 회전, 흐름, 추락)가 비행 물리에 그대로 나타납니다. 실제 기체의 수치를 근사한 교육용 모델이며 실기체 튜닝 값으로 쓰면 안 됩니다.

## 웹 배포 (GitHub Pages)
1. 저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 바꿉니다.
2. 변경 사항이 `main` 브랜치에 들어가면 `.github/workflows/pages.yml` 이 자동으로 배포합니다 (Actions 탭에서 **Run workflow** 로 직접 실행도 가능).
3. 주소
   - 드론 정비 시뮬레이터: `https://<GitHub 사용자명>.github.io/korea-airspace/simulator/`
   - 드론 공역 지도: `https://<GitHub 사용자명>.github.io/korea-airspace/`
4. 관리자 기록을 받으려면 [docs/관리자-기록-구글시트.md](docs/관리자-기록-구글시트.md) 대로 Google 시트를 연결하고 `simulator/js/config.js` 에 주소를 넣습니다.

정적 파일만 있으므로 Netlify·Cloudflare Pages 등에 저장소 폴더를 그대로 올려도 됩니다.

## 데이터 출처 — 반드시 읽어주세요
| 모드 | 공역 데이터 | 주소 검색 |
|---|---|---|
| 기본 (키 없음) | `data/zones.js` 내장 **개략** 데이터 | OpenStreetMap Nominatim |
| V-World 키 입력 | 국토교통부 V-World **공식** 공역 레이어(지도 + 판정) | V-World 검색 API |

내장 데이터는 공항 관제권(반경 9.3km), 원자력시설(3.7km/18.5km), P-73, P-518, R-75 등을 **근사한 원/다각형**입니다.
실제 고시 경계와 다를 수 있으니 실제 비행 전에는 V-World 키를 설정하거나 [드론원스톱](https://drone.onestop.go.kr)에서 확인하세요.
특히 P-73은 대통령 집무실 위치에 따라 바뀌므로 `data/zones.js`에서 중심 좌표를 확인해 주세요.

### V-World 키 설정
1. https://www.vworld.kr 회원가입 → 인증키 발급 (사용 API: 2D 데이터, WMS/WFS, 검색, 지오코더)
2. 서비스 URL에 앱을 배포할 주소(예: `https://내도메인`, 로컬 테스트는 `http://localhost:8080`) 등록
3. 앱 우측 ⚙ → 키 입력 → 저장

## 실행
### 웹
```bash
npm start
```
→ http://localhost:8080 . 정적 파일이므로 GitHub Pages·Netlify 등 아무 정적 호스팅에 그대로 올리면 됩니다.
(HTTPS 주소에서 열면 휴대폰에서 "홈 화면에 추가"로 앱처럼 설치됩니다.)

### Android / iOS 네이티브 앱
```bash
npm install
npx cap add android
npm run android
```
Android Studio가 열리면 실행/APK 빌드. iOS는 macOS + Xcode에서 `npx cap add ios` 후 `npm run ios`.
네이티브 앱에서 현재 위치를 쓰려면 Android `AndroidManifest.xml`에 위치 권한, iOS `Info.plist`에 `NSLocationWhenInUseUsageDescription`을 추가하세요.
