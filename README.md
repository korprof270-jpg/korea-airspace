# 드론 공역 지도 (대한민국)

지도에서 비행금지구역·관제권·비행제한구역을 보고, **주소를 입력하면 그 지점에서 드론을 날릴 수 있는지** 판정하는 앱입니다.
하나의 코드로 **웹 브라우저**, **설치형 앱(PWA)**, **Android/iOS 네이티브 앱(Capacitor)** 에서 모두 동작합니다.

## 기능
- 지도에 공역 표시 (금지 = 빨강 면, 관제권 = 보라 점선, 제한 = 주황 빗금, 원전 외곽 = 빨강 점선)
- 범례에서 유형별 켜기/끄기, 확대 시 공역 이름표 표시, 판정 지점에 걸린 공역 강조
- 주소/장소 검색 → 해당 지점 판정: **비행 가능 / 비행승인 필요 / 비행 불가**
- 지도 아무 곳이나 탭해서 판정, ◎ 버튼으로 현재 위치 판정
- 근처 공역 경고 (경계 2km 이내)
- URL로 바로 조회: `index.html?q=서울 여의도공원` 또는 `?lat=37.52&lng=126.92`
- 오프라인에서도 내장 데이터로 판정 (서비스 워커 캐시)

## 데이터 출처 — 반드시 읽어주세요
| 모드 | 공역 데이터 | 주소 검색 |
|---|---|---|
| 기본 (키 없음) | `data/zones.js` 내장 **개략** 데이터 | OpenStreetMap Nominatim |
| V-World 키 입력 | 국토교통부 V-World **공식** 공역 레이어(지도 + 판정) | V-World 검색 API |

내장 데이터는 공항 관제권(반경 9.3km), 원자력시설(3.7km/18.5km), P-73, P-518, R-75 등을 **근사한 원/다각형**입니다.
실제 고시 경계와 다를 수 있으니 실제 비행 전에는 V-World 키를 설정하거나 [드론원스톱](https://drone.onestop.go.kr)에서 확인하세요.
특히 P-73은 대통령 집무실 위치에 따라 바뀌므로 `data/zones.js`에서 중심 좌표를 확인해 주세요.

### V-World 키 설정
1. https://www.vworld.kr 회원가입 → 인증키 발급 (사용 API: 2D 데이터, WMS/WFS, 검색, 지오코더)
2. 서비스 URL에 앱을 배포할 주소(예: `https://내도메인`, 로컬 테스트는 `http://localhost:8080`) 등록
3. 앱 우측 ⚙ → 키 입력 → 저장

## 실행
### 웹
```bash
npm start
```
→ http://localhost:8080 . 정적 파일이므로 GitHub Pages·Netlify 등 아무 정적 호스팅에 그대로 올리면 됩니다.
(HTTPS 주소에서 열면 휴대폰에서 "홈 화면에 추가"로 앱처럼 설치됩니다.)

### Android / iOS 네이티브 앱
```bash
npm install
npx cap add android
npm run android
```
Android Studio가 열리면 실행/APK 빌드. iOS는 macOS + Xcode에서 `npx cap add ios` 후 `npm run ios`.
네이티브 앱에서 현재 위치를 쓰려면 Android `AndroidManifest.xml`에 위치 권한, iOS `Info.plist`에 `NSLocationWhenInUseUsageDescription`을 추가하세요.

## 드론 시뮬레이터 — 하늘길 FPV (`sim/`)
지도 화면의 🎮 버튼 또는 `http://localhost:8080/sim/` 로 실행하는 **3D 드론 비행 게임**입니다.

**PC·웹에서 쓰는 방법**
- **웹 주소로**: 저장소 Settings > Pages > Source 를 "GitHub Actions" 로 두면 `main` 에 올라갈 때마다 자동 배포됩니다(`.github/workflows/pages.yml`).
  주소는 `https://<계정>.github.io/korea-airspace/sim/` 형태입니다.
- **PC 앱처럼 설치**: Chrome·Edge 로 위 주소를 연 뒤 주소창의 설치 아이콘(또는 메뉴 > 앱 설치)을 누르면 전체 화면 앱으로 설치되고, 한 번 연 뒤에는 오프라인에서도 실행됩니다.
- **PC 에서 바로 실행**: 저장소를 내려받아 Windows 는 `드론시뮬레이터-실행.bat`, macOS·Linux 는 `./run-sim.sh` 를 실행하거나 `npm run sim` (Node.js 필요). 파일을 더블클릭해 `file://` 로 여는 방식은 브라우저 보안 정책 때문에 동작하지 않습니다.
설치·빌드 없이 브라우저에서 바로 돌아가며(Three.js 내장), 그림·소리는 모두 코드로 생성합니다.

| 모드 | 내용 |
|---|---|
| 🏁 레이싱 | 게이트(사각·링·깃발·아치·다이브) 또는 경로 체크포인트를 순서대로 통과. AI 라이벌, 랩 타임, 최고 기록 저장 |
| 🎥 트래킹 | 차량·사람·보트·드론 등 움직이는 피사체를 화면 중앙·적정 거리에 담아 따라가며 촬영 점수 획득 |
| 🌀 프리스타일 | 롤·플립·요 스핀·파워 루프·다이브·근접 비행·배면 비행·갭 통과를 감지해 콤보 점수 |
| ⚔️ 서바이벌 | 레이저·미사일·아이템(수리·미사일·실드·부스터·과충전·EMP)으로 겨루는 점수제 전투 — 데스매치 / 거점 파괴전 / 화물 운반전 |
| 🎯 챌린지 | 혼자 또는 AI 윙맨과 편대로 수행하는 임무 — 기지 방어, 포탑 소탕, 호송 작전, 긴급 보급, 모선 격추 |

- **맵 4종** (만화풍 그래픽: 단계 음영 + 외곽선)
  - 네온 시티: 하늘탑·관문 빌딩이 있는 금융가, 모노레일 순환선, 지면보다 낮은 천변과 다리, 공사장, 야시장, 대관람차 놀이공원
  - 붉은 협곡: 댐과 저수지, 암석 아치, 폭포 골짜기, 흔들다리, 바늘귀(슬롯) 협곡, 호수 분지, 광산, 풍력 단지, 고대 유적
  - 석양의 항만: 컨테이너선과 부두 크레인, 사장교, 정유 단지와 냉각탑, 조선소, 어시장, 공사장, 조차장, 방파제 등대
  - 네온 아레나: S자 터널, 슬라럼, 큐브 정글, 메자닌, 나선 계단, 플랫폼 타워, 관중석
- **조종**: 스틱 MODE 1~4, 비행 모드 ACRO / HORIZON / ANGLE / ALT HOLD / LOITER(GPS) 를 비행 중 `1`~`5`·`M` 으로 전환, 레이트(감도) 조절
- **시점**: `C` 키로 1인칭(FPV) ↔ 3인칭(추적) ↔ 지상 시점 전환
- **파일럿 HUD**: 속도·고도 테이프, 나침반, 자세계, 스틱 모니터, 비행 모드 배지, 추력 게이지, 목표 거리판, 레이더.
  설정 > "HUD·효과"에서 항목별로 켜고 끄며, 비행 중 `H` 키로 전체/최소/끄기 전환
- **게이트 안내**: 게이트를 통과하면 다음 게이트까지 흐르는 화살표와 빛기둥이 나오고, 화면 밖이면 방향과 거리를 표시
- **상태별 효과**: 공격·명중·격추·충돌·조준/락온·피해·실드·저체력 등에 화면 흔들림, 색 효과, 효과음, 진동(게임패드·모바일). 세기는 설정에서 조절
- **입력**: 키보드(WASD + 방향키), 게임패드·USB RC 조종기(축 지정 가능), 모바일 터치 가상 스틱
- **정비소**: 기체 등급 5종(성능) + 프레임 6종·캐노피·프로펠러·스킨·색상·LED·연기 꼬리로 외형 변경
- 설정·기록은 브라우저(localStorage)에 저장됩니다. 대전 상대와 팀원은 모두 AI 이며 온라인 멀티플레이는 포함되어 있지 않습니다.
- 열차·차량·보트·곤돌라·풍력 날개 같은 움직이는 물체에도 충돌 판정이 있고, 세게 부딪히면 기체가 부서집니다. 전투 모드에서는 5초 뒤 재출격합니다.

```
sim/index.html, sim.css   화면
sim/js/main.js, post.js, toon.js   렌더러·후처리(외곽선·블룸·FXAA)·툰 재질·메뉴/게임 상태
sim/js/physics.js         비행 역학과 비행 모드 컨트롤러
sim/js/input.js           키보드·게임패드·터치 → 스틱 모드, 진동
sim/js/world.js, env.js, textures.js   맵 빌더·하늘/물/지형 셰이더·절차적 텍스처
sim/js/maps/              맵 정의(코스·피사체·임무 데이터 포함)와 맵별 보조 모듈
sim/js/modes/             레이싱(게이트 안내 raceguide.js)·트래킹·프리스타일·서바이벌·챌린지
sim/js/hud.js, combathud.js   파일럿 HUD
sim/js/feel.js, audio.js, fx.js   화면 효과·효과음·파티클
sim/js/combat.js          전투(무기·아이템·AI 드론·포탑)
sim/vendor/               Three.js r160 (MIT)
```

