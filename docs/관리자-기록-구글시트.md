# 웹 배포용 관리자 기록 (Google 시트)

웹(GitHub Pages 등)에 올린 시뮬레이터는 교육생이 **종료**를 누르면 기록을 관리자의 Google 시트로 보냅니다.
교육생 화면에는 결과가 나오지 않고, 시트에만 쌓입니다.

## 1. 기록용 시트 만들기
1. Google 드라이브에서 새 스프레드시트를 만듭니다 (예: `드론 정비 실습 기록`).
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 기본 코드를 지우고 [`관리자-기록-apps-script.gs`](./관리자-기록-apps-script.gs) 내용을 붙여 넣고 저장합니다.

## 2. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포** → 유형 **웹 앱**.
2. **다음 사용자 인증 정보로 실행: 나**, **액세스 권한이 있는 사용자: 모든 사용자** 로 정하고 배포합니다.
3. 권한 확인 창이 뜨면 허용합니다.
4. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.

## 3. 시뮬레이터에 주소 넣기
`simulator/js/config.js` 의 `recordUrl` 에 복사한 주소를 넣고 main 브랜치에 올립니다.

```js
window.SIM_CONFIG = {
  recordUrl: "https://script.google.com/macros/s/....../exec",
};
```

## 확인
시뮬레이터에서 이름 입력 → START → 마지막 단계 **완료 → 종료**를 누르면, 몇 초 안에 시트에 **기록**·**상세** 탭이 생기고 한 줄씩 추가됩니다.

## 알아 둘 점
- 웹 앱 주소를 아는 사람은 누구나 시트에 줄을 추가할 수 있습니다. 주소를 공개된 곳에 올리지 마세요(시뮬레이터 코드 안에는 들어갑니다).
- 전송이 실패하면 기록은 교육생 기기에 남고, 다음에 페이지를 열 때 다시 보냅니다.
- claude.ai 게시 페이지에서 쓸 때는 이 설정 없이 페이지 자체의 공유 기록과 '기록 관리' 화면을 씁니다.
