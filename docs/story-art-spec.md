# 「노을의 날개」 인물 일러스트 규격

스토리 대화 장면의 인물 그림은 지금 코드로 그린 SVG 초상화를 쓰고 있다.
아래 규격으로 그린 그림(외주·직접 제작·생성 도구)을 넣으면 그대로 전신 입간판으로 바뀐다.

## 파일 규격
- 형식: 배경이 투명한 PNG (또는 WebP)
- 크기: 세로 2400px 안팎, 가로 1200~1600px. 전신(머리~발끝), 정면 또는 3/4 측면, 서 있는 자세
- 발끝이 그림 아래 끝에 닿게. 머리 위 여백은 전체 높이의 3~5%
- 표정마다 한 장씩: `normal` 기본, `smile` 웃음, `angry` 화남, `sad` 슬픔, `surprise` 놀람, `serious` 진지
  - 최소한 `normal` 한 장만 있어도 된다. 없는 표정은 `normal`로 대신한다
  - 표정 차분은 몸은 그대로 두고 얼굴(눈썹·눈·입·홍조)만 바꾼다
- 파일 이름: `<id>_<표정>.png` → `sim/img/story/chars/` 에 넣는다

## 등록
`sim/img/story/chars/art.js` 의 `ART` 에 한 줄 추가한다.

```js
export const ART = {
  서하린: { id: "harin", ext: "png", exprs: ["normal", "smile", "serious"] },
};
```
