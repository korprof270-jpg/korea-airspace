# 일러스트 팀 화풍 가이드 (「노을의 날개」 인물 입간판)

목표: 모바일 수집형 게임 대화 장면의 **전신 입간판** 수준. 코드로 작성한 SVG지만 "벡터 일러스트"로 보이게 한다.
지금의 단순 SVG 초상화(sim/js/portraits.js)는 기준 미달 예시다 — 그보다 훨씬 정교해야 한다.

## 캔버스
- `viewBox="0 0 1200 2400"`, 배경 투명. 전신이 화면 높이를 채운다: 머리 꼭대기 y≈90~140, 발끝 y≈2370~2395
- 인물은 가로 중앙(x≈600) 기준. 팔·무기·머리카락이 좌우로 뻗어도 되지만 0~1200 안에
- 등신: 성인 7.5~8등신(머리 높이 ≈ 290~310), 유리(10대 후반) 7등신, 바우는 어깨가 넓고 큰 체구
- 자세: 정면~3/4 측면, 체중이 한쪽 다리에 실린 콘트라포스토. 손 하나는 동작(헤어 넘기기·헤드셋 잡기·렌치 들기 등)으로 인물 성격 표현

## 그리기 방식
- 외곽선: 진한 남보라 `#1a1626` 계열, 굵기 3~5 (바깥 실루엣 5, 안쪽 디테일 2~3), `stroke-linejoin="round"`
- 채색: 셀 셰이딩 3단 — 기본색 / 그림자(기본색보다 어둡고 채도·색상 이동, 피부 그림자는 붉은 쪽) / 하이라이트. 광원은 **왼쪽 위**
- `linearGradient`·`radialGradient` 적극 사용: 머리카락 세로 그라데이션 + 윤기 띠(흰색 반투명 곡선 하이라이트), 금속·가죽 반사, 천의 주름 그림자
- 림 라이트: 오른쪽 가장자리에 장면 조명색(하늘색 #8fe8ff 또는 포인트 색) 얇은 빛 테두리
- 옷은 주름(팔꿈치·허리·무릎), 솔기, 지퍼, 버클, 벨트, 파우치, 휘장 등 디테일을 충분히. 휴마 연합 휘장 = 마름모 안의 날개
- 머리카락은 덩어리(클럼프) 단위로 겹겹이, 잔머리 몇 가닥. 뻣뻣한 단일 도형 금지
- 손은 손가락이 보이게 그린다(벙어리장갑 모양 금지)
- 그림자 `filter` 는 쓰지 말 것(성능). 대신 겹친 반투명 도형으로 표현

## 얼굴과 표정
- 애니메 스타일: 큰 눈(눈 높이 ≈ 머리 높이의 1/7), 홍채 세로 그라데이션 + 동공 + 큰 하이라이트 1 + 작은 하이라이트 2, 위 속눈썹 굵게, 아래 속눈썹 가늘게, 쌍꺼풀 선
- 코는 작은 그림자 획, 입은 표정별로 형태가 확실히 다르게
- `svg(expr)` 에서 **몸은 동일하고 얼굴(눈썹·눈·입·홍조·땀/눈물)만** 바뀐다
  - normal 기본, smile 웃음(눈웃음 또는 활짝), angry 화남(눈썹 V, 이 드러냄 가능), sad 슬픔(눈썹 八, 눈물 맺힘), surprise 놀람(눈 크게·작은 홍채·벌린 입), serious 진지(가늘게 뜬 눈, 다문 입)

## 코드 규격
- 파일: `sim/img/story/chars/src/<id>.mjs`
  ```js
  export const ID = "harin", NAME = "서하린";
  export function svg(expr = "normal") { return `<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 1200 2400">...</svg>`; }
  ```
- 외부 리소스·폰트·이미지 금지, 순수 SVG. `id` 속성은 `<id>-` 접두사로(다른 인물과 겹치지 않게)
- 한 장 크기 목표 40~150KB
- 빌드: `node tools/build-chars.mjs <id>` → `sim/img/story/chars/<id>_<expr>.svg`
- 확인: `node tools/preview-chars.cjs <id> /tmp/<id>.png` 후 그 PNG를 직접 보고 고친다. **최소 3회 이상 보고 고치기 반복**
- 다른 게임·작품의 캐릭터를 베끼지 않는다. 설정표(docs/story-art-spec.md)의 독자 디자인으로
