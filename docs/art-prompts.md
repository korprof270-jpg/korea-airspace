# 인물 일러스트 프롬프트 (그림 생성 AI용)

- 한 인물당 먼저 **기본(normal) 전신 1장**을 만들어 마음에 드는 것을 고른 뒤, 그 그림을 참조 이미지(캐릭터 고정·image reference)로 넣고 **표정만 바꾼 5장**을 만든다
- 비율 **1:2 세로**(또는 9:16), 단색 **녹색 배경**(#00FF00) → 받으면 배경을 따서 넣는다
- 파일 이름: `<id>_<표정>.png` (normal smile angry sad surprise serious) — 예) `harin_smile.png`

## 공통 꼬리말 (모든 프롬프트 끝에 이미 포함됨)
```
full body standing character art for a mobile gacha game visual novel, head to toe fully visible, centered, dynamic contrapposto pose, high-detail anime illustration, glossy cel shading with soft painterly gradients, sharp specular highlights on hair and eyes, crisp clean lineart, rim light, tactical sci-fi military costume details, plain solid bright green background (#00FF00), no shadow on background, no text, no logo, no watermark, single character only
```

## 네거티브 프롬프트 (지원되는 경우)
```
cropped, cut off feet, cut off head, multiple characters, background scenery, text, watermark, signature, extra fingers, deformed hands, blurry, low quality, chibi, 3d render, photo
```

## 표정 바꾸기 (참조 이미지 + 아래 한 줄)
```
same character, same outfit, same pose, same framing, only change facial expression to: gentle smile / angry with furrowed brows and gritted teeth / sad with teary eyes and lowered brows / surprised with wide eyes and open mouth / serious with narrowed eyes and closed mouth
```
