# 드론공학 연구동향 분석 코딩북

각 논문을 제목·주제어·초록·학과(학위논문) 또는 학술지명(학술논문)을 근거로 코딩한다. 판단 근거가 부족하면 제목을 우선한다.

## rel (분석 대상 여부)
- Y: 드론(무인비행장치·무인항공기·UAV·UAS·멀티콥터·UAM용 무인기 등)이 연구의 주된 대상이거나 핵심 연구 도구(데이터 취득 등)인 경우
- N: 드론이 언급만 되거나 부수적인 경우, 드론과 무관한 경우(예: 지상 로봇, 일반 하천 모형, 정책 일반)

## target (연구대상: 주된 기술 요소 1개) / targets (해당되는 모든 요소)
- T1 기체·구조: 기체·형상 설계, 공력, 구조해석, 복합재, 진동·소음, 랜딩기어
- T2 추진·동력: 모터·프로펠러·로터, 배터리·연료전지·하이브리드, 전력·충전, 열관리
- T3 제어·항법: 자세·위치 제어, 경로계획, GNSS/INS/VIO/SLAM 항법, 충돌회피, 자율비행, 군집·편대, 착륙
- T4 통신·네트워크·보안: 통신 링크, 이동통신·중계, MEC, 네트워크 최적화, 사이버보안·포렌식, 암호·인증
- T5 센서·임무장비·영상처리: 카메라·LiDAR·열화상·분광 센서, 임무장비·매니퓰레이터, 영상처리·객체탐지(드론 탑재/드론 영상 처리 알고리즘 자체가 주 기여인 경우)
- T6 운용·관제·안전: UTM·공역·관제, 운용 체계·스케줄링·임무할당, 안전성·위험도 평가, 사고, 불법드론 탐지·대응(안티드론), 인증·감항
- T7 응용·활용: 드론을 도구로 활용하여 특정 분야 문제(측량 정확도, 작황, 시설물 상태, 환경 관측 등)를 해결하는 연구로, 기여가 드론 기술이 아니라 활용 결과에 있는 경우
- T8 기타: 위에 해당하지 않음(교육, 산업 분석 등)

## app (응용분야 1개)
- A1 농업·산림, A2 물류·배송, A3 건설·측량·국토(공간정보 포함), A4 시설물 점검·유지관리(교량·전력·태양광·건물외관 등), A5 재난·안전·소방, A6 환경·기상·해양, A7 국방·보안·대테러(안티드론 포함), A8 교통·도심항공(UAM/AAM), A9 기타 응용(엔터테인먼트, 레저, 공공서비스 등), A0 범용(특정 응용분야 없음)

## method (주된 연구방법 1개) / methods (적용된 모든 방법)
- M1 이론·해석: 수학적 모델링, 해석해, 안정성 증명, 최적화 문제 정식화(수치 검증이 부차적인 경우)
- M2 수치해석·시뮬레이션: CFD, FEM, 비행·네트워크 시뮬레이션(MATLAB/Simulink, Gazebo, SITL, NS-3 등), 수치 최적화 실험
- M3 실험(실험실): 지상 시험대·추력시험·풍동·HILS·실내 실험·성능 측정
- M4 비행시험·현장실증: 실기체 실외 비행시험, 현장 적용·실증, 대상지에서 드론으로 데이터 취득 후 분석
- M5 설계·개발·구현: 시스템·하드웨어·소프트웨어의 설계·개발·구현이 주 기여(검증은 부차적)
- M6 데이터 기반 분석: 기계학습·딥러닝 모델 학습·평가, 기존 데이터셋 기반 영상·점군·통계 분석
- M7 조사·문헌·정책 분석: 설문, 델파이·AHP, 전문가 조사, 문헌·사례·정책·법제 분석

주된 방법은 결과 도출과 검증에 가장 핵심적인 방법이다. 예: 알고리즘 제안 후 시뮬레이션으로만 검증 → M2. 드론 영상 취득 후 딥러닝 적용 → M6(취득이 현장이면 methods에 M4 포함).

## level (검증 수준: 가장 높은 단계 1개)
- L1 이론(검증 없음 또는 해석만), L2 시뮬레이션, L3 실험실·지상시험, L4 실외 비행시험, L5 현장 실증(실제 운용 환경·시범사업), L0 해당 없음(조사·정책 연구)

## kw (핵심 키워드)
- 논문 내용을 대표하는 한국어 키워드 3~5개(‘드론’ 제외, 표준 용어로 정규화: 예 ‘딥러닝’, ‘경로계획’, ‘정사영상’, ‘안티드론’)
